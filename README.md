# Деректер қоры · Электрондық оқу құралы

Онлайн-кітап (GitHub Pages). Парақтау анимациясы және дыбысы бар, толығымен қазақ тілінде.

## Файлдар
- `content.js` — кітаптың мәтіні мен мазмұны (**осыны өзгертесіз**)
- `index.html`, `style.css`, `script.js` — кітаптың жұмыс механизмі
- `assets/logo.png` — университет логотипі (өз файлыңызды осы атпен салыңыз)

## GitHub-қа жүктеу
1. GitHub-та жаңа репозиторий жасаңыз (мысалы `derekqor-kitap`), Public.
2. Осы папканың барлық файлдарын жүктеңіз (Add file → Upload files).
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, папка `/ (root)` → Save.
4. 1–2 минуттан кейін кітап `https://<логин>.github.io/derekqor-kitap/` мекенжайында ашылады.

## Жаңа бет қосу
`content.js` ішіндегі `pages` тізіміне блок қосыңыз:
```js
{ title: "Жаңа тақырып", html: `<p>Мәтін...</p>` },
```
Мазмұны (оглавление) мен сілтемелер автоматты түрде жаңарады.

Кез келген адам репозиторийді `Fork` жасап немесе ZIP түрінде жүктеп, өз кітабын жасай алады.
